# lecture-deck-remake

A Claude skill that rebuilds a boring or confusing lecture, lab or tutorial deck
(PDF or PPTX) as a clear, engaging Slides artifact, in English, Hebrew, or both.

It adds a running example, one everyday analogy per concept, quizzes every few
slides, drawn diagrams next to the source's own pictures, slide animations, and
eye-catching command chips. It also covers Hebrew right-to-left layout.

## Install

Copy this folder to `~/.claude/skills/lecture-deck-remake/`, so you end up with:

```
~/.claude/skills/lecture-deck-remake/SKILL.md
~/.claude/skills/lecture-deck-remake/references/patterns.md
```

## Use

Share a course deck and run `/lecture-deck-remake`, or just say "remake this
presentation" or "explain it better".
